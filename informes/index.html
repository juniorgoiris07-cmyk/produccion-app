Configuración inicial

Esto se hace una sola vez en este celular/PC.

Necesitás la URL de la aplicación web de Google Apps Script conectada a la planilla de Google Sheets donde se cargan los lotes. La obtenés desde la hoja: Extensiones → Apps Script → Implementar → Nueva implementación (tipo "Aplicación web", acceso "Cualquier usuario"). Pegá acá la URL que termina en /exec.
