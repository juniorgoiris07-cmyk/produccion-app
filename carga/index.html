Configuración inicial

Esto se hace una sola vez en este celular/PC.

Necesitás la URL de la aplicación web de Google Apps Script conectada a la planilla de Google Sheets. La obtenés desde la hoja: Extensiones → Apps Script → Implementar → Nueva implementación (tipo "Aplicación web", acceso "Cualquier usuario"). Pegá acá la URL que termina en /exec. Si ya configuraste la app de Informes en este mismo teléfono, se usa la misma URL automáticamente.
